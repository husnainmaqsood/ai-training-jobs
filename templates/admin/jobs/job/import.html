How matching works

  • If a row has an external_id, it updates the job with that ID on the same platform.
  • Otherwise it updates the job on the same platform with the same link (ignoring http/https, www., trailing slashes and tracking parameters such as utm_*).
  • A link that already belongs to a job on another platform, or matches more than one job, is rejected rather than guessed.
  • Jobs missing from the file are left alone, unless you choose Full snapshot and confirm closing them.
